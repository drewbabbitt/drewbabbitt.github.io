GALLERY IMAGES

Put photographs here, then list them in ../../gallery.json. The gallery page
builds itself from that file, so nothing else ever needs editing.

  aspect   4:5 portrait, 1200 x 1500 works well
  format   jpg, quality 82, keep each one under 300KB
  naming   client-01-before.jpg, client-01-after.jpg

A before/after pair shows as one wide tile with both shots side by side.
A single image shows on its own. gallery.json has an example of each.

Until a real photograph is listed, the page shows the coming soon copy plus
empty numbered frames so the layout can be reviewed. Set show_placeholders
to false in gallery.json to hide those frames.

CONSENT
Never publish a photograph without written permission from the client in
it. The site says every photo is shared with permission and never before,
so that promise has to be true.
